使用指南

导入与识别

从「01 导入文件」选择 PDF 或图片，先保存一份 .ipdfedit 工程。小范围修改可先识别本页，跨页替换再识别全部页面。识别结果用于定位和编辑文字，底图中的旧字需要另行清除。

精确查找替换

  1. 点击「查找替换」，输入原文字与新文字，例如 ACME → NOVA。
  2. 选择「全部页面」或「当前页」。保持「严格定位」「同时清除底图中的旧文字」「保留其他原版内容」勾选。
  3. 点击「预览匹配结果」，核对页码、原文字、替换后内容和处理说明。取消勾选不需要修改的项目。
  4. 执行「替换匹配项」。待核对项保持原样，不计入完成数量。
  5. 放大检查处理结果，再保存工程。通过「更多 → 查看操作记录」查看本次计划、处理数量和校验结果。

严格模式对独立定位且识别清晰的文字框执行自动替换；品牌混在整行正文中、缺少精确单词坐标或识别不确定时，转为待核对。替换批次失败或取消时，恢复这批操作之前的文字、底图和撤销历史。

局部补擦与照片字标

到对应页放大查看，使用「框选区域」仅围住要处理的文字，再点「擦除选区」并填写替换文案。注意避开相邻日期、其他标识、分隔线和说明文字。复杂纹理修复后仍需目视检查；不满意时可撤销、缩小或调整选区后重做。

范围校验保护的是允许区域之外的底图与计划内的文字变化，选区内部的修复是否自然仍需人工判断。

编辑与统一字号

点击文字框可修改内容、字体、字号、颜色、对齐和角度；拖动可移动位置，拖动四角可调整区域。通过「统一字号」按标题、正文、页脚等用途设置一致大小。多行正文建议先合并为段落。

仅替换品牌时，其余内容继续保持原版底图。需要编辑更多正文时，再明确选择并重建相应区域，避免为局部需求执行全页重绘。

工程保存与导出

.ipdfedit 工程保存原始资产、修复底图和可编辑文字，可关闭后再次打开。自动备份在「更多 → 打开自动备份」中恢复。

PDF 适合分享和打印；PowerPoint 使用可编辑文字框，适合后续演示文稿调整。导出后检查照片文字、字体和排版。

运行配置

默认 2 个 CPU 线程，可通过 IPDF_CPU_THREADS 调整为 1–4。M1、M2 级别以及更高配置使用相同的工作流。实际计算量与页面分辨率、批量页数和修复区域有关。

只修改替换词时复用已有 OCR；小范围修改优先处理对应页面和选区，相同修复内容会复用缓存。更换修复模型后可清除修复缓存。

# Changelog

## 1.2.0 — 2026-10-31

- Introduce the ReGlyph PDF desktop workflow for scanned and image-backed document text.
- Add strict replacement previews, confidence-based review, document fingerprints and scoped pixel validation.
- Restore complete replacement transactions, including history, after failure or cancellation.
- Save self-contained projects with original and repaired page assets.
- Add role-based font sizes, paragraph merging, local touch-ups, layered PDF and editable PPTX export.
- Reduce repeated repair work with solid-background fast paths, bounded crop batching and content-addressed caching.
- Add macOS/Windows launchers, isolated runtime installation, synthetic examples and automated regression checks.
